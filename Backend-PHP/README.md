# Backend-PHP 🚀

This repository contains beginner to intermediate **Backend development practice projects** using **PHP and HTML**.  
It focuses on form handling, basic backend logic, and simple frontend layouts.

---

## 📂 Repository Contents

| File Name | Description |
|---------|------------|
| `Examination-Students-s-Seating-Chart.html` | Examination hall students seating chart using HTML tables |
| `form.html` | Basic HTML form for user input |
| `registration-form.php` | PHP backend script to handle form data |
| `Alex-Portfolio.html` | Simple portfolio webpage |
| `Project Module.html` | Empty Box Project Module |
| `Online Bookstore Application.html` | Online Bookstore Application |

---

## 🧠 Technologies Used

- **HTML5**
- **CSS (basic styling)**
- **PHP (Form handling & backend logic)**

---

## 🧪 Project Descriptions

### 1️⃣ Examination Students Seating Chart
- Built using **HTML table**
- Displays seat number and student names
- Useful for exam hall management and academic projects

### 2️⃣ HTML Form
- Collects user details
- Designed to send data to PHP backend

### 3️⃣ PHP Registration Form
- Receives form data using `POST`
- Demonstrates basic PHP backend concepts
- Can be extended to connect with a database (MySQL)
